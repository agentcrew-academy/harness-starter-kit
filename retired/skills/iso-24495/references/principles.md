# ISO 24495-1 — Principles, Interpretation, and Sources

This file summarizes the publicly documented content of ISO 24495-1:2023
(*Plain language — Part 1: Governing principles and guidelines*) and states
how this skill interprets it. It paraphrases principles; it does not
reproduce the standard's text.

## What ISO 24495-1 Is

Published June 2023 by ISO Technical Committee 37, developed with the
International Plain Language Federation (IPLF). It is the first international
standard that defines plain language, and it defines it as a **reader
outcome**, not a style: language is plain when its wording, structure, and
design let the intended readers easily find what they need, understand it,
and use it.

Two properties matter for this skill:

1. **Language-independent.** ISO's own abstract: the document "applies to
   most, if not all, written languages, but provides examples only in
   English." The principles govern any language; the techniques must be
   built per language. That is exactly the split this skill implements.
2. **Principles-based, not rules-based.** The standard gives four governing
   principles with guidelines on how to interpret and apply them. It contains
   no approved-word dictionary and no hard numeric limits. Every numeric
   threshold in this repo's technique files (sentence length targets, list
   thresholds, paragraph limits) is this project's own proxy.

The series continues: Part 2 (2025) covers legal communication, Part 3
covers science writing. This skill implements Part 1 only.

## The Four Principles, As This Skill Applies Them

**1. Relevant — readers get what they need.**
Identify the reader and purpose first; the same text can be plain for one
audience and opaque for another. Select content for that reader; cut what
does not serve them. In rewriting practice: deleting a paragraph the reader
does not need is a legitimate and often the single most effective edit.

**2. Findable — readers can easily find what they need.**
Order content by the reader's priority, not the author's chronology. Put
conclusions and required actions first. Use informative headings (a heading
should answer, not tease), one topic per paragraph, and lists for parallel
items so the eye can index the page.

**3. Understandable — readers understand on first reading.**
Common words over rare ones. Short sentences carrying one idea each.
Explicit actors. Terms defined at first use, then used consistently — never
rotated with synonyms. No unexplained jargon, no stacked hedges, no
nominalized actions where a verb is available.

**4. Usable — readers can use the information.**
If the reader must do something, write it as a doable step with an explicit
actor, object, and deadline. "The form should be submitted by applicants in
a timely manner" fails; "Submit the form by March 31" passes.

The principles are ordered: relevance decisions come first (what to say),
findability next (where to put it), then understandability and usability
(how to word it). A rewrite that only polishes sentences while keeping an
author-centric structure has applied half the standard.

## Copyright Boundary

The full standard is a paid, licensed document. This project does not quote
it and has been built from the publicly available principle framework (ISO's
published abstract and scope, and the IPLF's freely published definition and
framework). This mirrors the approach of the companion skill
[asd-ste100-skill](https://github.com/danyuchn/asd-ste100-skill), which
encodes rule categories without reproducing ASD's licensed dictionary.
